# AI Fortune Telling App

I Ching hexagram and BaZi charting with AI interpretation.

## Stack
- React/Vite frontend
- Node/Supabase Edge Functions backend
- Local reverse proxy for Edge Functions

## Local development
Copy `.env.docker.example` to `.env.docker`, configure Supabase variables, then start frontend, local Edge Functions and the gateway as described in the repository docs.

## Status
Development repository. External AI and Supabase credentials are required for full functionality; no credentials are included.
